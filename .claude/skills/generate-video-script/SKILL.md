# Skill: Generate TikTok/Reels Script

## Trigger
When the user asks to generate a video script, TikTok script, Reels script, or social video content for One Prompt Away.

## Instructions

Generate a 60-second TikTok/Instagram Reels script for One Prompt Away.

### Script Structure

```
HOOK (0-3 seconds)
- One sentence that stops the scroll
- Question or bold statement
- Must create curiosity gap

BODY (3-48 seconds)
- Step-by-step demonstration
- Use [VISUAL DIRECTIONS] in brackets for what to show on screen
- [SHOW: screenshot of...] for screen recordings
- [TEXT ON SCREEN: ...] for text overlays
- [TRANSITION: cut/fade/swipe] for transitions
- Keep it visual — show, don't tell

CTA (48-60 seconds)
- Clear call to action
- "Follow για περισσότερα prompts"
- Mention @onepromptaway
- Optional: "Link στο bio για full article"
```

### Brand Voice (Video)
- Even more casual than articles
- Direct, energetic, concise
- OK to use emoji in video scripts
- Speak to camera style

### Visual Style
- Dark theme matching brand (#0D1117 background)
- Teal (#2DD4BF) for highlights and emphasis
- Monospace font for prompts/code shown on screen
- Clean screenshots, no clutter

### Output
Save to `content/drafts/{slug}-script.md`

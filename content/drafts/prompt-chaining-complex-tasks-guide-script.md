# TikTok/Reels Script: Prompt Chaining: Πώς Σπάω Πολύπλοκα Tasks σε Μικρά Αλυσιδωτά Prompts
## Duration: 60 seconds

### HOOK (0-3s)
Σταμάτα να γράφεις prompts-τέρατα 500 λέξεων που δεν δουλεύουν.

### BODY (3-48s)
Αντί για ένα τεράστιο prompt, χρησιμοποίησε prompt chaining. [ΔΕΙΞΕ ΟΘΟΝΗ ΜΕ ΜΕΓΑΛΟ PROMPT] Αυτό εδώ; Δεν δουλεύει. [SPLIT SCREEN: 4 ΜΙΚΡΑ PROMPTS] Αυτά όμως; Magic. Πρώτο prompt: βρες μου γωνίες. [ΔΕΙΞΕ OUTPUT] Δεύτερο: φτιάξε outline με αυτή τη γωνία. [PASTE & ΔΕΙΞΕ] Τρίτο: γράψε μόνο αυτή την ενότητα. [ZOOM ΣΤΟ RESULT] Τέταρτο: polish το όλο κείμενο. [BEFORE/AFTER COMPARISON] Κάθε prompt κάνει ΜΙΑ δουλειά καλά.
